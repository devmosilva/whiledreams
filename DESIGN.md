# While Dreams Design System

## Direction

The approved visual world is **Loop Essencial**. A luminous off-white surface, deep navy typography and a blue-violet ribbon turn the While Dreams symbol into the organizing system of the page. The result should feel precise, premium and approachable rather than futuristic or generically “AI”.

## Foundations

- Surface: `#F8F8F8`
- Primary ink: `#0A162B`
- Brand violet: `#6353F0`
- Deep violet: `#382CC1`
- Secondary text: `#656773`
- Rules: `#DFE1E8`
- Body and display type: Atkinson Hyperlegible
- Display tracking never tighter than `-0.04em`
- Controls use firm rectangular geometry with 10–14px radii.

## Composition

The first viewport pairs monumental copy with the official loop symbol branching into Sites, Sistemas, Automação and IA aplicada. Below the fold, the same continuous-system idea should connect problems, process, examples and conversion without falling back to a repeated grid of generic cards.

## Interaction

- Primary actions use navy and shift to deep violet on hover.
- Secondary actions use an outlined light surface.
- Keyboard focus uses a visible violet outline with offset.
- Motion is optional, purposeful and removed for `prefers-reduced-motion`.
